Wymusza maksymalną częstotliwość odświeżania (120 Hz). ⚠ Zwiększa zużycie baterii.

settings put system min_refresh_rate 120
↩ Przywróć (60 Hz):
settings put system peak_refresh_rate 60 && settings put system min_refresh_rate 60

🚀 Skrypt ADB Boost

Uruchom adb_boost.bat na PC z podłączonym telefonem. Skrypt:

  • ✅ Zmniejsza skale animacji (0.5x)
  • ✅ Opcjonalnie wymusza 120 Hz
  • ✅ Czyści pamięć podręczną DNS
  • ✅ Opcjonalnie wyłącza aplikacje bloatware

📋 Komendy ręczne (ADB)

Skopiuj i wklej do wiersza poleceń (wymaga adb w PATH):

Sprawdź połączenie: adb devices
Animacja okien 0.5x: adb shell settings put global window_animation_scale 0.5
Animacja przejść 0.5x: adb shell settings put global transition_animation_scale 0.5
Czas trwania animatora 0.5x: adb shell settings put global animator_duration_scale 0.5
Wymuś 120 Hz: adb shell settings put system peak_refresh_rate 120 && adb shell settings put system min_refresh_rate 120
Wyczyść DNS: adb shell ndc resolver flushdefaultif
Przywróć animacje 1.0x: adb shell settings put global window_animation_scale 1.0 && adb shell settings put global transition_animation_scale 1.0 && adb shell settings put global animator_duration_scale 1.0

⚠ Tryb root jest opcjonalny i ryzykowny. Używasz na własną odpowiedzialność.

Wymaga Magisk lub innego roota + aplikacji Termux (z pakietem tsu).

🔧 Skrypt Termux Root

Skopiuj termux_root_boost.sh do telefonu i uruchom w Termux:

  • ✅ Wykrywa root (su)
  • ✅ Wykrywa governor CPU i przełącza na performance
  • ✅ Czyści pamięć podręczną
  • ✅ Opcjonalnie wyłącza bloatware
  • ✅ Zapisuje backup ustawień do przywrócenia

📋 Komendy root (Termux)

Uruchom Termux z rootem (tsu), potem wklej komendy:

Sprawdź governor CPU: cat /sys/devices/system/cpu/cpu0/cpufreq/scaling_governor
Ustaw governor na performance: echo performance | su -c 'tee /sys/devices/system/cpu/cpu*/cpufreq/scaling_governor'
Wyczyść pamięć podręczną: sync && echo 3 | su -c 'tee /proc/sys/vm/drop_caches'
Włącz Tryb Gry: settings put system game_mode 1
Wyłącz animacje: settings put global window_animation_scale 0.5 && settings put global transition_animation_scale 0.5 && settings put global animator_duration_scale 0.5
Przywróć governor (powersave/schedutil): echo schedutil | su -c 'tee /sys/devices/system/cpu/cpu*/cpufreq/scaling_governor'

⚠ Czego NIE robić

  • ❌ Nie wyłączaj thermal throttling (ryzyko uszkodzenia telefonu)
  • ❌ Nie usuwaj aplikacji systemowych (pm uninstall)
  • ❌ Nie zmieniaj ustawień jądra/SELinux
  • ❌ Nie zabijaj procesów systemowych
  • ❌ Nie zmieniaj ustawień GPU na sztywno (różne urządzenia)
